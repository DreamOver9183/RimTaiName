[h1]邊緣臺名 RimTaiName[/h1]
把小人的英文姓名翻成[b]臺灣繁體中文[/b]。原版名字全部離線翻譯，[b]不需要任何金鑰[/b]；想翻譯其他 Mod 的名字或取全新的中文名，再加上你自己的免費 Gemini API Key 即可。

[h2]功能[/h2]
在角色資訊卡按改名（新生兒命名視窗也適用），視窗會多出：
[list]
[*][b]鎖頭[/b]：名、暱稱、姓各有一個，鎖住的欄位不會被更改。
[*][b]翻譯姓名[/b]：依序查你的個人快取、內建字典（收錄原版全部 24,596 個名字詞，第 1、2、4 層逐筆校對），查不到的才一次送給 Gemini。
[*][b]生成中文名[/b]：依小人的性別、背景故事、文化與異種族，替未鎖定的欄位取一個新的中文名（需要 API Key）。鎖定的欄位會作為風格參考。
[*][b]還原[/b]：未鎖定的欄位恢復為開窗時的內容。
[/list]
[list]
[*]官方繁中已有譯名的名字（帝國貴族、怪人暱稱等）沿用官方譯名。
[*]暱稱用意譯（Fox → 狐狸、Doc → 老醫），人名簡稱與本名一致（Chris → 克里斯）。
[*]日文名用漢字（Haruka → 遙），中文拼音、越南、韓國姓名用對應漢字（Wu → 吳、Nguyen → 阮、Kim → 金）。
[*]縮寫保留英文字母（MJ → MJ、Big D → 大D）。
[*]你把譯名改掉再按「確定」，Mod 會記住你的修正，之後同名的小人優先使用。
[*]等待 Gemini 回應時，點視窗外不會關閉；等待中你改過的欄位不會被覆寫。
[/list]

[h2]申請免費的 Gemini API Key（只有翻譯其他 Mod 的名字與生成中文名需要）[/h2]
[olist]
[*]用 Google 帳號登入 [url=https://aistudio.google.com/]Google AI Studio[/url]。
[*]進入「API Keys」頁面，按「Create API key」。建議建在[b]沒有啟用帳單[/b]的專案上。
[*]複製金鑰。2026 年 5 月起新發的金鑰以 [b]AQ.[/b] 開頭，預設只能呼叫 Gemini API。
[*]回到遊戲：選項 → Mod 設定 → 邊緣臺名，貼上金鑰後按「儲存」（或直接按「從剪貼簿貼上」），再按「測試連線」確認。
[/olist]

[h2]金鑰安全[/h2]
[list]
[*]金鑰不會寫進存檔或 Mod 設定檔。Windows 以 DPAPI 加密存在本機設定資料夾，只有目前的 Windows 帳號能解密；macOS／Linux 只在本次遊戲期間記憶，關閉遊戲後需重新輸入。
[*]只有你按下「翻譯姓名」「生成中文名」或「測試連線」時，才會以 HTTPS 連到 Google 的 Gemini API；金鑰只放在請求標頭，不會出現在網址或記錄檔。
[*]請為本 Mod 建立一把專用金鑰，並建在沒有啟用帳單的專案上：只能用免費額度，即使外洩也不會產生費用。
[*]舊式 AIza 開頭的金鑰，請在 Google Cloud 主控台限制為只能呼叫 Generative Language API。
[*]懷疑外洩時，到 AI Studio 刪除並重建金鑰，再在設定頁按「清除金鑰」。
[*]同一個遊戲中的其他 Mod 理論上仍可能讀取記憶體中的金鑰，這無法完全防止。
[/list]

[h2]隱私與額度[/h2]
[list]
[*]送出的只有姓名；「生成中文名」另外送出性別、背景故事標題、文化、異種族與年齡層。本 Mod 不做任何統計或回報。
[*]Gemini 免費層送出的內容會被 Google 用於改善產品。依 Gemini API 條款，歐洲經濟區、瑞士與英國的使用者只能使用付費服務。
[*]免費額度以專案計算，每天太平洋時間午夜（臺灣時間 15:00 或 16:00）重置；用完時會顯示重置時間。「測試連線」也會用掉 1 次額度。
[*]兩次請求之間預設至少間隔 3 秒，可在設定頁調整。
[/list]

[h2]相容性[/h2]
[list]
[*]RimWorld 1.6；需要 [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077]Harmony[/url]。
[*]不新增任何存檔資料（沒有 ThingComp、WorldComponent、GameComponent），只透過原版命名流程改名字，可以隨時加入或移除。
[*]只處理人類的命名視窗；動物與機械體的改名視窗不受影響。
[*]從手動安裝版改用創意工坊版時，Mod 設定（模型、間隔等）需要重新設定；API Key 與個人快取存在遊戲設定資料夾，兩版共用。
[/list]
